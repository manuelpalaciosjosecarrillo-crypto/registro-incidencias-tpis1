# RegistroIncidencias

## Propósito
Aplicación Android diseñada para el registro y gestión de incidencias.

## Herramientas utilizadas
* Android Studio
* Kotlin
* Jetpack Compose
* Git y GitHub

## Estado actual
* **Funciona:** Proyecto Android base con pantalla inicial prototipada.
* **Falta implementar:** Lógica de eventos, ciclo de vida y persistencia de datos.

## Cómo abrir el proyecto
1. Clonar este repositorio localmente.
2. Abrir Android Studio y seleccionar "Open".
3. Navegar hasta la carpeta del proyecto y esperar a que Gradle sincronice.
